# Banking77

`train.csv` (10,003 messages) and `test.csv` (3,080) are the Banking77 intent-detection dataset from PolyAI, copied unchanged from
https://github.com/PolyAI-LDN/task-specific-datasets (`banking_data/`). It is licensed under
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

Casanueva, Temčinas, Gerz, Henderson and Vulić, "Efficient Intent Detection with Dual Sentence Encoders", NLP4ConvAI 2020.
https://arxiv.org/abs/2003.04807
